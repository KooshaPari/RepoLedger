## Chronological finding

The recurring object across the creator's work is an executable search space rather than one model type:

```text
representation
+ local or agent-level operators
+ environment
+ persistent state and artifacts
+ evaluator or selection pressure
+ repeated execution
```

The sequence changes the substrate and evaluator:

- explicit organisms and endogenous survival;
- neural local-update rules;
- neural and evolutionary function approximation;
- human aesthetic selection over mutable representations;
- embodied LLM agents in Minecraft;
- shared-artifact multi-agent experiments;
- recursive code modification against an external objective;
- real-game tournaments with recordings, status, errors, and incumbent retention.

## Important contradiction

The chronology does not support a fleet-wide rule of “maximize emergence” or “remove central coordination.” Later Mindcraft work adds structured task files, blocked actions, deterministic evaluation, safety switches, and action-level collaboration. Those are corrections to failure modes observed in looser systems.

The most defensible portfolio translation remains:

```text
enable bounded exploration
+ preserve evidence and rollback
+ keep global invariants explicit
+ evaluate in the real environment
+ tighten or loosen coordination based on measured failure
```
